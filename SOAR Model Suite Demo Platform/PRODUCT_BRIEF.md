\f0\fs24 \cf0 # SurgAI Forge Website \'97 Product Brief\
\
## Objective\
\
SurgAI Forge should help surgeons and computer scientists discover, use, and contribute to surgical AI resources.\
\
The website should lead users toward action rather than simply describe the initiative.\
\
## Core Audience Principle\
\
### Surgeons\
Use and adapt surgical AI.\
\
Primary desired behaviors:\
\
- understand what surgical AI can do\
- see real model outputs\
- use models through SOAR\
- use Mint for no-code inference/basic training\
- request access to resources\
\
### Computer Scientists\
Extend and advance surgical AI.\
\
Primary desired behaviors:\
\
- use models, code, datasets, and annotations\
- build on released work\
- evaluate against shared benchmarks\
- participate in the Hugging Face leaderboard\
- contribute improved models\
\
## Primary Website Areas\
\
- Home\
- About\
- For Surgeons\
- For Computer Scientists\
- Open Resources\
- Model Demo\
- Papers\
- Blog\
- Support\
- Request Access\
\
## Core Resources\
\
- SOAR\
- Mint\
- SurgVision+500\
- Surgical annotations\
- Models and checkpoints\
- GitHub resources\
- Hugging Face leaderboard\
\
## Access\
\
Working assumption:\
\
One SurgAI Forge access request grants access to applicable downloadable resources.\
\
Some public website content and model demonstrations remain viewable without access.\
\
## Model Demo Goal\
\
Allow a user to quickly understand what SurgAI Forge model outputs look like on real surgical video.\
\
The model demo uses precomputed outputs only.\
\
No browser-based inference is performed.\
\
